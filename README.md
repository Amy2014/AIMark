# MARK

网页标注扩展。点选元素并写下说明，可用于报 Bug、提需求，或复制给 AI。

## 加载

1. Chrome 打开 `chrome://extensions`（Edge 用 `edge://extensions`）。
2. 打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选中本文件夹（含 `manifest.json` 的这一层）。
4. 打开要标注的网页，点工具栏里的 MARK 图标。
5. 弹窗里点「开启」。页面右下角出现按钮。

同一标签页刷新后会自动再开启，已写的标注还在。点「关闭」，或关掉这个标签页，之后就不会自动开。

浏览器内置页（`chrome://`、`edge://`）不能注入。改完代码后，到扩展管理页点本扩展的刷新。

## 改标注逻辑

直接改 `lib/ai-annotate.js`，然后在扩展管理页点本扩展的刷新。这个目录不依赖业务仓库。
